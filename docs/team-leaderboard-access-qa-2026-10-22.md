# Every team challenge leaderboard

Active team players and their authorized families can now discover every team shooting challenge, including finished challenges they did not enter. Removed the private list function's enrollment requirement for discovery and its silent 20-item cap. Ownership/guardian authorization for the requested player and active membership in each returned team remain required. Snapshot read authorization, peer daily-entry privacy, staff-only audit details, enrollment and write authorization are unchanged.

The family dashboard now has a clear “View team leaderboard” link, and additional challenge links lead directly to standings. The challenge page has a team leaderboard selector, scrolls directly to the leaderboard when linked, preserves the chosen child across read-only archives and current challenges, resets old date/invite state on challenge changes, and explains read-only viewing when the player was not enrolled. A failed selector fetch has an explicit retry while the current standings remain visible.

Baseline regression with disposable real actors reproduced coach list20/26 and family/player list1/26. The same backend tests passed after the migration: 26 visible challenges, historical ranks/totals visible, no other-team access, no forged-player access, no writes to teammates or unenrolled archives, own current entries still writable, and peer days/audit absent. Real UI tests cover parent-managed and independent-player dashboard links and switching between archive/current leaderboards. Existing shooting layout/save/invitation/error tests also run across Chromium/WebKit/Firefox. Fixture accounts, teams, players and challenges are scoped and cleaned in finally blocks; the real team is not modified.

Full npm check passed (28 existing lint warnings; optional local Chrome prerender unavailable, static crawlability passed). Database security advisors reported no error-level issues. The reviewed private-function migration is applied; no table or RLS policy changes. Mobile browser tests emulate devices rather than certify physical devices.
